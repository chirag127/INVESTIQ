## Technical Architecture Standard Across All 25 Sites

1. **Framework:** Standalone static Astro 5 + React sites.
2. **Hosting:** GitHub Pages via GitHub Actions (`https://chirag127.github.io/<repo-name>/`), 100% free with zero hosting bills.
3. **Downloads Policy:** **Zero file downloads.** All guides, calculators, and decision tools run natively in the browser.
4. **Data Privacy:** Local-only calculations with zero backend telemetry or financial data transmission.
5. **Shared Assets:** Shared atomic CSS tokens, mathematical calculation libraries, and privacy scanner script.
