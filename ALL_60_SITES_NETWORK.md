## Operational Architecture Summary

1. **Zero File Downloads:** All 60 websites are 100% interactive web applications. Readers consume the deep-dive articles and use the reactive tools directly on screen.
2. **Individual Repositories:** Each property can be initialized as an independent, lightweight Astro static site on GitHub (`https://chirag127.github.io/<repo-name>/`), deployed via free GitHub Actions.
3. **Shared Foundation:** All 60 websites share the same robust mathematical engine (`src/lib/finance-math.ts`), privacy scanner (`scripts/privacy-scanner.js`), and accessible design tokens.
