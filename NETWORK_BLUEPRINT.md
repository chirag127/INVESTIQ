# THE INVESTIQ 25-SITE DIGITAL NETWORK BLUEPRINT

**Architecture Strategy:** Unbundling the monolithic knowledge base into **25 specialized, standalone static sites** hosted on GitHub Pages or individual domains. Each website operates as an authority hub with its own focused calculators, regulatory references, and dedicated deep-dive guides—with **no heavy binary downloads**.

---

## Summary of the Multi-Site Architecture

1. **Clean Separation:** Each topic lives on its own lightweight, fast-loading static site with dedicated meta tags and specialized calculators.
2. **Zero Website Downloads:** All content and interactive tools run directly in the browser with no offline book/file download requirement.
3. **Cohesive Design & Shared Engine:** All 25 sites share the same open-source core math engine (`src/lib/finance-math.ts`), privacy scanner (`scripts/privacy-scanner.js`), and accessible dark/light theme tokens.
4. **Free-First Deployment:** Every site can be deployed as an independent GitHub repository under your GitHub account (`https://chirag127.github.io/<repo-name>/`) with zero hosting or cloud billing costs.
